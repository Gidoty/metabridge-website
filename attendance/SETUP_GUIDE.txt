METABRIDGE ACADEMY — ATTENDANCE SYSTEM
SETUP GUIDE
================================================================

WHAT YOU WILL GET
-----------------
After setup (takes about 10 minutes):

- A live web app link for each cohort:
    Cohort 1 link  →  [your URL]?c=C1
    Cohort 2 link  →  [your URL]?c=C2
    Cohort 3 link  →  [your URL]?c=C3

- An admin panel link:
    Admin link     →  [your URL]?admin=true

Share the cohort links with your students.
Keep the admin link private — only you use it.


================================================================
STEP 1 — CREATE A NEW GOOGLE SHEET
================================================================

1. Go to Google Drive (drive.google.com)
2. Open your MetaBridge Academy folder
3. Click: + New → Google Sheets
4. Name it: "MetaBridge Academy — Attendance System"


================================================================
STEP 2 — OPEN APPS SCRIPT
================================================================

With your new Google Sheet open:
1. Click the menu: Extensions
2. Click: Apps Script
3. A new browser tab opens — this is the Apps Script editor


================================================================
STEP 3 — PASTE THE BACKEND CODE
================================================================

In the Apps Script editor:
1. You will see a file called "Code.gs" on the left
2. Click on it (it should already be selected)
3. SELECT ALL the existing code in the editor and DELETE it
4. Open the file "Code.gs" from this folder
5. COPY all the text in that file
6. PASTE it into the Apps Script editor
7. Click the SAVE button (floppy disk icon, or Ctrl+S)


================================================================
STEP 4 — ADD THE STUDENT FORM HTML FILE
================================================================

In the Apps Script editor:
1. Click the + button next to "Files" on the left panel
2. Select: HTML
3. Type the filename exactly: StudentForm
   (DO NOT type StudentForm.html — Apps Script adds .html automatically)
4. Click OK / Add
5. A new empty "StudentForm.html" file appears
6. SELECT ALL its content and DELETE it
7. Open "StudentForm.html" from this folder
8. COPY all the text in it
9. PASTE it into the Apps Script editor
10. Click SAVE (Ctrl+S)


================================================================
STEP 5 — ADD THE ADMIN PANEL HTML FILE
================================================================

In the Apps Script editor:
1. Click the + button again
2. Select: HTML
3. Type the filename exactly: AdminPanel
4. Click OK / Add
5. SELECT ALL and DELETE the default content
6. Open "AdminPanel.html" from this folder
7. COPY all the text in it
8. PASTE it into the Apps Script editor
9. Click SAVE (Ctrl+S)


================================================================
STEP 6 — RUN THE SETUP FUNCTION
================================================================

This creates all the sheets automatically.

1. In the Apps Script editor, click on "Code.gs" (left panel)
2. Near the top of the editor, find the function dropdown
   (it may say "select function" or show a function name)
3. Click it and choose: initializeSheets
4. Click the ▶ Run button
5. FIRST TIME ONLY: A permissions pop-up will appear
   - Click: Review permissions
   - Choose your Google account (gideono1991@gmail.com)
   - Click: Advanced → Go to MetaBridge (unsafe)
     (it says "unsafe" because it is your own script — this is normal)
   - Click: Allow
6. Run initializeSheets again — it should complete successfully
7. Go back to your Google Sheet — you will now see these tabs at the bottom:
   - MASTER_REGISTER (all students, including any from the live form)
   - C1_ATTENDANCE
   - C2_ATTENDANCE
   - C3_ATTENDANCE


================================================================
STEP 7 — DEPLOY AS A WEB APP
================================================================

1. In Apps Script, click the blue "Deploy" button (top right)
2. Click: New deployment
3. Click the gear icon next to "Type" and select: Web app
4. Fill in the settings:
   - Description: MetaBridge Academy Attendance System
   - Execute as: Me (gideono1991@gmail.com)
   - Who has access: Anyone          ← THIS MUST BE "Anyone"
5. Click: Deploy
6. COPY the Web app URL that appears — it looks like:
   https://script.google.com/macros/s/AKfycbX.../exec
7. Click: Done

⚠️  IMPORTANT — "Who has access" MUST be set to "Anyone"
    If it is set to anything else (e.g. "Only myself" or
    "Anyone within [organization]"), the cohort links will
    fail with a "Sorry, unable to open the file" error.
    If this happened to you, see the FIX section below.

================================================================
FIX — "SORRY, UNABLE TO OPEN THE FILE" ERROR
================================================================

This error appears when the Web App access is not set to "Anyone".
Follow these steps to fix it:

1. Go to Apps Script
2. Click the blue "Deploy" button (top right)
3. Click: Manage deployments
4. Click the pencil (edit) icon on your existing deployment
5. Change "Who has access" to: Anyone
6. Change "Version" to: New version
7. Click: Deploy
8. The URL remains the same — your cohort links will now work

After this change, test by opening the URL with ?c=C1 in a
PRIVATE / INCOGNITO browser window (this simulates a student
who is not signed in to Google).

HOW NEW STUDENTS AUTO-APPEAR IN THE ATTENDANCE FORM
================================================================

The attendance system reads the enrolment registration sheet
(Google Sheet ID: 1n49CjCnNxWX9sEaUUb0Vpjz14i6m4j-3cFwOk2ClEx4)
automatically. Any student who fills the registration form will
appear in the attendance dropdown the next time the attendance
form is opened — no code changes needed.

REQUIREMENTS FOR THIS TO WORK:
The registration form's response sheet must have a header row
where the column names contain these keywords:
  - "name"   → e.g. column header: "Full Name"
  - "cohort" → e.g. column header: "Cohort"
  - "email"  → e.g. column header: "Email Address" (optional)

The cohort column in the form must clearly indicate C1, C2, or C3.
Any of these formats are understood automatically:
  C1 / C2 / C3
  Cohort 1 / Cohort 2 / Cohort 3
  1 / 2 / 3

New students receive IDs continuing from the last existing student.
Student 16 onwards: MA/Cn/016/26, MA/Cn/017/26, and so on.

PERMISSIONS: Both the attendance sheet and the registration sheet
must be owned by the same Google account (gideono1991@gmail.com).
Since both are in your Google Drive, this works automatically.


================================================================
HOW TO ADD MORE STUDENTS MANUALLY (IF NEEDED)
================================================================

1. Open Apps Script → Code.gs
2. Find the STUDENT_REGISTER section (around line 30)
3. Add the new student to the correct cohort using this format:
   { sn: 16, id: 'MA/C1/016/26', name: 'Student Full Name', email: 'email@gmail.com' }
   (Use the next available sn number)
4. Save (Ctrl+S)
5. Click Deploy → Manage deployments
6. Click the pencil/edit icon on your existing deployment
7. Change "Version" to "New version"
8. Click: Deploy
9. The same URL still works — students don't need a new link


================================================================
HOW TO ADD MORE COURSES
================================================================

1. Open Apps Script → Code.gs
2. Find the COURSES array (around line 15)
3. Add your new course inside the array:
   'New Course Name',
4. Save, then re-deploy (same steps as adding students above)


================================================================
HOW TO CHANGE THE ADMIN PASSWORD
================================================================

1. Open Apps Script → Code.gs
2. Find this line near the top:
   const ADMIN_PASSWORD = 'Admin2026';
3. Change 'Admin2026' to your new password
4. Save and re-deploy
